# 💻 معرض الأعمال الهندسية الشخصي (Professional Engineering Portfolio)
## 📝 نبذة عن المشروع
موقع ويب شخصي متكامل ومتجاوب يعرض الأعمال الهندسية والمشاريع التقنية في مجالات **الأمن السيبراني، هندسة الشبكات، والذكاء الاصطناعي**.
تم تصميم الموقع بأسلوب برمجي نظيف واحترافي يعتمد على **فصل البيانات عن واجهة العرض**، مما يتيح تحديث المحتوى بسهولة دون الحاجة إلى تعديل كود HTML.
## 🛠️ الميزات التقنية
### 1️⃣ فصل البيانات المركزي (Data Decoupling)
- تخزين كافة بيانات الموقع (المعلومات الشخصية، المشاريع، المهارات، والروابط) داخل ملف **`data.json`** منظم.
- يسمح هذا التصميم بتحديث أو إضافة مشاريع جديدة بسهولة تامة.
### 2️⃣ جلب البيانات ديناميكياً (Dynamic Data Fetching)
- استخدام **Fetch API** لجلب البيانات من ملف `data.json` عند تحميل الصفحة.
- دالة `renderProfile()` تقوم بقراءة الهيكل وتوليد المحتوى ديناميكياً.
### 3️⃣ واجهة مستخدم متطورة ومتجاوبة
- تصميم عصري بـ **HTML5** و **CSS3** بنمط **Dark Cyberpunk**.
- تجاوب كامل مع جميع الأجهزة باستخدام Media Queries.
- تأثيرات بصرية سلسة (Glow Effects و Hover Transitions).
### 4️⃣ تصميم مرن لعرض المشاريع
- **Detailed Layout**: للمشاريع الكبيرة والمعقدة.
- **Card Layout**: للمشاريع الصغيرة والأدوات.
- ظهور أزرار الروابط تلقائياً حسب توفرها.

## 📂 هيكل المشروع

- 📄 **`index.html`** — الملف الرئيسي
- 📄 **`data.json`** — قاعدة البيانات المحلية
- 📷 **`my-photo.jpg`** — الصورة الشخصية

## 🚀 دليل التشغيل والتخصيص
### 2️⃣ تشغيل المشروع محلياً
لا يعمل الموقع بشكل صحيح إذا تم فتح ملف `index.html` مباشرة بسبب قيود أمن المتصفح (CORS).
**الحل الموصى به:**
- استخدم امتداد **Live Server** في **Visual Studio Code**.
- افتح مجلد المشروع، ثم اضغط بزر الماوس الأيمن على `index.html` واختر **Open with Live Server**، أو اضغط **Go Live** في الشريط السفلي.
- سيفتح الموقع على: `http://127.0.0.1:5500`
### 3️⃣ تخصيص الموقع لمعلوماتك الشخصية
افتح ملف **`data.json`** وقم بتعديل الأقسام التالية:
- **الملف الشخصي**: غيّر الاسم، المسمى الوظيفي، والنبذة داخل كائن `"profile"`.
- **الصورة الشخصية**: استبدل `my-photo.jpg` أو غيّر `"avatar_url"`.
- **المشاريع**: أضف أو عدّل المشاريع داخل مصفوفة `"projects"`:
  - `"layout": "detailed"` → للمشاريع الكبيرة.
  - `"layout": "card"` → للمشاريع الصغيرة.
- **روابط المشاريع**: أضف الروابط داخل `"links"` لكل مشروع.
- **المهارات والتواصل**: حدّث `"skills"` و `"contact"`.
### 4️⃣ نشر الموقع أونلاين (GitHub Pages)
1. ارفع المشروع إلى مستودع **عام** على GitHub.
2. اذهب إلى **Settings** → **Pages**.
3. تحت **Source**، اختر فرع `main` ثم اضغط **Save**.
4. بعد دقائق قليلة، سيكون موقعك متاحاً على الرابط:
   `https://اسم-المستخدم.github.io/اسم-المستودع`
